# Gallery

Photo albums made from pictures in Media.

1. Switch it on in Settings › Inserts.
2. Open **Albums** (in the Media chapter), make an album and press pictures to add them.
3. Put `[[gallery: album-name]]` in any post or page.

Settings: pictures across (2–4), captions (each picture's description), and the lightbox.
Pictures without a description are marked, because the description is what screen readers say.
