# Events

Things happening, with a date, a time and a place.

1. Switch it on in Settings › Inserts.
2. Open **Events** (in the Posts chapter) and add one.
3. The site gets a page at `/events` (add it to a menu in Site menus), each event an
   "Add to my calendar" file, and `/events.ics` a calendar people can subscribe to.
4. Put `[[events]]` (the next three) or `[[events: 5]]` in any post or page.

Settings: the page's name and a line under it, whether past events show, and whether
old ones are forgotten after a number of days.
